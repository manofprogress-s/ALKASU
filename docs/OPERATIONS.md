# Kullanım kılavuzu (kısa)

## Satış
1. **Satış** ekranında ürüne dokunun veya barkod okutun. Birim (şişe/paket/koli) sepette değiştirilir.
2. Veresiye veya depozito takibi gerekiyorsa **müşteri seçin**.
3. Damacana satışında sepette **"Getirilen boş"** sayısını ayarlayın. Eksik boş için depozito otomatik eklenir.
4. **Ödeme al** → Nakit / POS / Veresiye / Bölünmüş → **Satışı tamamla**.
5. İnternet yoksa satış telefonda saklanır, üst çubukta "gönderilmedi" görünür. Bağlantı gelince otomatik gönderilir.

## İptal ve iade (yönetici)
- Kasa günü kapanmadan: **Satışlar → satış → Satışı iptal et**.
- Sonrasında: **İade al** → kalem ve miktar seçin, sağlam/kusurlu belirleyin.
- Satış personeli **İade talebi** oluşturur, yönetici onaylar.

## Mal kabul
- Depo: **Mal kabul → Yeni** → ürün, birim, miktar, bedelsiz miktar, tedarikçiye verilen boş kaplar.
- Yönetici: kaydı açıp **alış fiyatlarını onaylar**. Maliyet bu anda güncellenir.

## Gün sonu (yönetici)
**Kasa → Gün sonu kapat** → sayılan nakit (küpür sayacı) → POS slip toplamı → yarına devreden nakit → kapat.
Fark tolerans üstündeyse açıklama zorunludur. Kapanan gün değiştirilemez.

## Sayım
**Stok → Sayım** → tam veya ürün seçerek kısmi → miktarları koli/adet karışık girin → **Kaydet** → yönetici **Onayla**.

## Excel
- Ürün/müşteri aktarma: **Ürünler → Excel'den aktar** (şablon aynı sayfada).
- Her liste ve raporda **Dışa aktar** → Excel veya CSV.
